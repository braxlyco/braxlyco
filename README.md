## Software built around the way you work

**Braxly** builds custom software, AI agents, bots, and connected digital tools for real business workflows. Whether the need is a focused internal tool or a complete platform, we turn the process into software people can actually use.

### What we build

| Area | What it can include |
| --- | --- |
| **Custom software** | Business systems, dashboards, desktop tools, and purpose-built applications. |
| **AI agents & bots** | Assistants and automations that help teams handle repetitive work and information. |
| **Portals & platforms** | Customer, staff, vendor, and operations portals with the workflows behind them. |
| **Integrations & automation** | APIs, data flows, notifications, and connections between existing systems. |
| **Mobile & field tools** | Practical apps for on-site work, scanning, and data capture. |

### Selected work

| Project | What it demonstrates |
| --- | --- |
| [**BrewNest**](https://github.com/braxlyco/BrewNest-Coffee-Management) | A modular coffee shop management system for sales, kitchen, inventory, procurement, and payments. Built with .NET and Blazor. |
| [**Workshop DMS**](https://github.com/braxlyco/DBM) | A workshop workflow from job cards and estimates through parts, invoicing, and audit history. Built with Django. |
| [**RFID Scanner**](https://github.com/braxlyco/RFID-Scanner-Java) | An offline Android UHF RFID tool for handheld scanning, tag tracking, and device diagnostics. Built with Java. |

### How we approach a build

We start with the workflow and the outcome it needs to produce. Then we design the interface, build the core, connect the moving parts, and test the result against real use. The technology follows the problem.
